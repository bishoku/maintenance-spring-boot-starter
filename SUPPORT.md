# Support

Use [GitHub Issues](https://github.com/bishoku/maintenance-spring-boot-starter/issues)
for usage questions, reproducible bugs and feature requests. Check the [README](README.md),
[operations guide](docs/operations.md), [upgrade notes](CHANGELOG.md) and existing issues first.

Include the starter, Spring Boot and Java versions; relevant sanitized configuration;
expected and actual behavior; and a small reproducer where possible. For transition failures,
include `details.phase` and `details.partialFailure`. Never post credentials or sensitive payloads.

Security concerns should be reported privately as described in [SECURITY.md](SECURITY.md).
Support is provided by maintainers and contributors on a best-effort basis, without an SLA.
