# v1.3.2 — Update mandatory dependency security baseline

Update the default non-optional Boot dependency graph while retaining runtime
compatibility with application-managed Boot 2.7 stacks on Java 17.

## Changes

- Upgrade the coherent build/default BOM from Boot 3.5.9 to **4.0.9**, including
  `spring-boot-autoconfigure`, `spring-boot` and Framework **7.0.10** transitives.
- Keep optional integrations optional and consumer dependency management authoritative.
- Add a reproducible minimal downstream-consumer audit, retained before/after evidence,
  and documentation distinguishing library-default, build/test and application graphs.
- Make local benchmark builds honor the root dependency baseline. GitHub Actions and
  library Java implementation are unchanged; benchmarks remain outside CI.

## Upgrade notes

Use your application's Boot parent/BOM to manage the complete runtime stack. An
application without dependency management now receives Boot 4.0.9 defaults. Java 17
remains required, the same JAR supports the tested Boot 2.7 runtimes, and Boot 2.7
continues using `management.endpoint.maintenance.enabled=true` rather than modern
Actuator access modes. No new maintenance settings or runtime behavior are introduced.

Boot 2.7 compatibility is functional: this update cannot fix vulnerable versions
selected by the application's own BOM. Scan and maintain that actual runtime graph.
The known early-exit race, property precedence and startup failure reporting behavior
documented for 1.3.1 remain unchanged.

## Validation

- Java 17 source matrix: **188 tests each** against Boot 3.5.9 and 4.0.9.
- Same local candidate JAR on real MicroK8s with Kafka/Rabbit: **236 startup checks**
  across Boot 2.7.0, 2.7.18, 3.5.9 and 4.0.9, plus **70 two-pod Boot 2.7 checks**.
  Management access while Service-excluded, maintenance exit and readiness recovery pass.
- Local 1.3.2 release packaging passed another **188 tests**; all **39 non-Maven
  entries** are byte-identical to the candidate used in Kubernetes.
- Minimal default downstream graph: **six OSV advisory matches before, zero after**
  as of 2026-11-07. This is a database/version match result, not a blanket security
  guarantee or exploitability finding. Optional build dependencies are a separate scope.

The [security and compatibility report](../benchmark/reports/DEPENDENCY_SECURITY.md)
records exact candidate hashes and raw results. Candidate E2E results are not presented
as tests of the signed Central artifact. The release workflow runs source tests, signs
and publishes binaries and attaches them to this release.
